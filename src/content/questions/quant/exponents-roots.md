## Q1
**difficulty:** Easy
**type:** Problem Solving
**topic:** Exponent Rules

What is the value of 2⁵ * 2³?

- A) 2⁸
- B) 2¹⁵
- C) 4⁸
- D) 4¹⁵
- E) 2²

**answer:** A
**fastest_path:** Same base → add exponents: 2⁵ × 2³ = 2⁸.
**explanation:** Product of same-base powers: a^m × a^n = a^(m+n). So 2⁵ × 2³ = 2^(5+3) = 2⁸. The base stays at 2; only the exponents combine.
**mistake_b:** Multiplied exponents: 5 × 3 = 15 → 2¹⁵.
**mistake_c:** Multiplied bases: 2 × 2 = 4, then added exponents → 4⁸.
**mistake_d:** Multiplied bases AND exponents → 4¹⁵.
**mistake_e:** Subtracted exponents instead of adding → 2².
**common_trap:** Multiplying the bases as well as the exponents.
**takeaway:** Same base, multiplication: add exponents (a^m × a^n = a^(m+n)). The base never changes during this operation.

## Q2
**difficulty:** Easy
**type:** Problem Solving
**topic:** Roots & Radicals

Simplify √50.

- A) 5
- B) 5*√2
- C) 2*√5
- D) 10*√5
- E) 25*√2

**answer:** B
**fastest_path:** 50 = 25 × 2 → √50 = 5√2.
**explanation:** Pull out the largest perfect-square factor. 50 = 25 × 2. So √50 = √25 × √2 = 5√2.
**mistake_a:** Computed only √25 = 5 (forgot the √2).
**mistake_c:** Reversed factor placement: 2√5 from 50 = 4 × 12.5 (incorrect setup).
**mistake_d:** Misfactored as 100 × 0.5; got 10√5.
**mistake_e:** Pulled out 2 instead of 25; got 25√2 (squared the wrong factor).
**common_trap:** Pulling out the smaller factor (e.g., √2) instead of the largest perfect square.
**takeaway:** To simplify √n, factor n into (perfect square × remaining). Memorize perfect squares: 4, 9, 16, 25, 36, 49, 64, 81, 100.

**topic:** Exponent Rules

What is the value of 3⁻²?

- A) -9
- B) -6
- C) -1/9

**answer:** E

**mistake_a:** Treated 3⁻² as −(3²) = −9.

**mistake_c:** Got the reciprocal but kept the negative: −1/9.
**mistake_d:** Computed 1/(3 × 2) = 1/6 (multiplied base × exponent in denominator).
**common_trap:** Treating negative exponents as making the result negative.
**takeaway:** a⁻ⁿ = 1/aⁿ. Negative exponents flip into denominators; they never produce negative values from positive bases.

## Q6
**difficulty:** Medium
**type:** Problem Solving
**topic:** Exponent Rules

Which of the following equals (x⁴ * y⁻²) / (x⁻¹ * y³)?

- A) x³ * y⁻⁵
- B) x⁵ * y⁻⁵
- C) x⁵ * y⁻¹
- D) x³ * y⁻¹
- E) x⁵ * y

**answer:** B
**fastest_path:** Subtract exponents: x^(4−(−1)) × y^(−2−3) = x⁵ × y⁻⁵.
**explanation:** Same-base division: a^m / a^n = a^(m−n). For x: 4 − (−1) = 5 → x⁵. For y: (−2) − 3 = −5 → y⁻⁵. Result: x⁵ × y⁻⁵.
**mistake_a:** x: 4 − 1 = 3 (forgot the double-negative).
**mistake_c:** y: −2 + 3 = 1 (added instead of subtracted), got y⁻¹.
**mistake_d:** Both errors: x³ and y⁻¹.
**mistake_e:** y exponent: subtracted wrong way, got y⁺¹.
**common_trap:** Mishandling double-negatives — subtracting a negative is *adding*.
**takeaway:** a^m / a^n = a^(m−n). When the denominator's exponent is negative, the subtraction becomes addition (m − (−n) = m + n).
**related_reading:** reading-quant-04-algebra-and-equations

## Q7
**difficulty:** Medium
**type:** Problem Solving
**topic:** Roots & Radicals

Simplify √12 + √27.

- A) √39
- B) 3*√13
- C) 5*√3
- D) 6*√3
- E) 13*√3

**answer:** C
**fastest_path:** Simplify: √12 = 2√3, √27 = 3√3. Sum = 5√3.
**explanation:** Radicals only add when they share the same radicand. Simplify each: √12 = √(4 × 3) = 2√3; √27 = √(9 × 3) = 3√3. Both share √3, so add coefficients: 2√3 + 3√3 = 5√3.
**mistake_a:** Computed √(12 + 27) = √39 (cannot add radicands inside one root).
**mistake_b:** Computed wrong simplification; got 3√13.
**mistake_d:** Coefficient addition slip: 2 + 3 = 6 instead of 5.
**mistake_e:** Added radicands and coefficients: (2+3)√(12+27) → 5√39 (wrong); rounded.
**common_trap:** Adding inside the radical (√a + √b ≠ √(a + b)) — this is one of the most common mistakes.
**takeaway:** Add radicals only after simplifying to matching radicands. √a + √b = √(a + b) is *false*; treat radicals like variables — only add when they're the same "kind."
**related_reading:** reading-quant-04-algebra-and-equations

## Q8
**difficulty:** Medium
**type:** Problem Solving
**topic:** Fractional Exponents

What is the value of 27^(2/3)?

- A) 3
- B) 6
- C) 9
- D) 18
- E) 81

**answer:** C
**fastest_path:** 27^(2/3) = (27^(1/3))² = 3² = 9.
**explanation:** Fractional exponent rule: a^(m/n) = (a^(1/n))^m. So 27^(2/3) = (27^(1/3))² = 3² = 9. Take the root first (smaller numbers); raising to the power second.
**mistake_a:** Computed 27^(1/3) = 3 and stopped (didn't square).
**mistake_b:** Computed 27 × 2/3 = 18, halved to ~6.
**mistake_d:** Computed 27 × 2/3 = 18.
**mistake_e:** Computed 27² / 3 = 729/3 = 243 (raised to 2 first, then divided by 3 — wrong).
**common_trap:** Treating a^(m/n) as a × m/n or as a^m / n.
**takeaway:** a^(m/n) = (a^(1/n))^m = (n-th root of a) raised to m. Take root first when n divides cleanly; small numbers are easier.
**related_reading:** reading-quant-04-algebra-and-equations

**topic:** Exponent Rules

If (2^a)³ = 2¹², what is a?

**common_trap:** Confusing (a^m)^n = a^(mn) with a^m × a^n = a^(m+n).
**takeaway:** Power of a power → multiply: (a^m)^n = a^(mn). Different from same-base product (add exponents). Memorize both.

## Q12
**difficulty:** Hard
**type:** Problem Solving
**topic:** Roots & Radicals

Rationalize the denominator: 6 / (√3 + 1).

- A) 6*√3 - 6
- B) 3*√3 - 3
- C) 3*√3 + 3
- D) 2*√3 + 2
- E) √3 - 1

**answer:** B
**fastest_path:** Multiply by conjugate (√3 − 1)/(√3 − 1): denom = 3 − 1 = 2; numer = 6(√3 − 1)/2 = 3√3 − 3.
**explanation:** To clear a sum/difference with a radical in the denominator, multiply by the *conjugate* (flip the sign between terms). Numerator: 6 × (√3 − 1) = 6√3 − 6. Denominator: (√3 + 1)(√3 − 1) = 3 − 1 = 2 (difference of squares). Result: (6√3 − 6)/2 = 3√3 − 3.
**mistake_a:** Computed 6(√3 − 1) without dividing by 2.
**mistake_c:** Used the same sign instead of conjugate.
**mistake_d:** Divided by 3 instead of 2; got 2√3 − 2.
**mistake_e:** Cancelled too aggressively; got √3 − 1.
**common_trap:** Forgetting to use the conjugate's flipped sign — multiplying by (√3 + 1)/(√3 + 1) doesn't clear the radical.
**takeaway:** Rationalize sums/differences with radicals using the *conjugate*: (a + b)(a − b) = a² − b². The result has no radical in the denominator.
**related_reading:** reading-quant-04-algebra-and-equations

## Q18
**difficulty:** Hard
**type:** Data Sufficiency
**topic:** Sign Analysis with Exponents

Is x > 0?

(1) x⁵ > 0.
(2) x² < x.

- A) Statement (1) ALONE is sufficient, but statement (2) alone is not sufficient.
- B) Statement (2) ALONE is sufficient, but statement (1) alone is not sufficient.
- C) BOTH statements TOGETHER are sufficient, but NEITHER statement ALONE is sufficient.
- D) EACH statement ALONE is sufficient.
- E) Statements (1) and (2) TOGETHER are NOT sufficient.

**answer:** D
**fastest_path:** (1) Odd power preserves sign: x⁵ > 0 → x > 0. (2) x² < x → 0 < x < 1 → x > 0. Both alone sufficient → D.
**explanation:** Statement (1): x⁵ > 0. Odd powers preserve sign — if x were negative, x⁵ would be negative. So x > 0. Sufficient.

Statement (2): x² < x rearranges to x − x² > 0 → x(1 − x) > 0. This holds when x and (1 − x) have the same sign. Both positive: 0 < x < 1. Both negative: x < 0 AND x > 1 (impossible). So 0 < x < 1, which is x > 0. Sufficient.

Each alone works → D.
**mistake_a:** Concluded only Statement 1 sufficient, missed Statement 2's resolution.
**mistake_b:** Concluded only Statement 2 sufficient.
**mistake_c:** Required both statements.
**mistake_e:** Concluded together insufficient.
**common_trap:** Assuming Statement 2 admits negative x without checking the sign diagram.
**takeaway:** Odd powers preserve sign (x⁵ > 0 ⟺ x > 0). For x² < x, factor: x(1 − x) > 0 → 0 < x < 1 (both positive case).
**related_reading:** reading-di-02-data-sufficiency-logic

## Q38
**difficulty:** Hard
**type:** Data Sufficiency
**topic:** Roots & Radicals

If n is a positive integer, is √(4n) an integer?

(1) n = 9t for some positive integer t.
(2) n = j² for some positive integer j.

- A) Statement (1) ALONE is sufficient, but statement (2) alone is not sufficient.
- B) Statement (2) ALONE is sufficient, but statement (1) alone is not sufficient.
- C) BOTH statements TOGETHER are sufficient, but NEITHER statement ALONE is sufficient.
- D) EACH statement ALONE is sufficient.
- E) Statements (1) and (2) TOGETHER are NOT sufficient.

**answer:** B
**fastest_path:** (1): n = 9t → √(4n) = 6√t. Integer only if t is a perfect square — inconsistent. (2): n = j² → √(4n) = √(4j²) = 2j. Always integer → B.
**explanation:** Statement (1): n = 9t. Then 4n = 36t and √(4n) = 6√t. Whether the result is an integer depends on t: if t = 1, √36 = 6 (integer, YES); if t = 2, √72 = 6√2 (not integer, NO). The answer varies → insufficient.

Statement (2): n = j² for some positive integer j. Then 4n = 4j² and √(4n) = √(4j²) = 2j. Since j is a positive integer, 2j is always a positive integer. The answer is always YES → sufficient.

Answer: B.
**mistake_a:** Concluded Statement (1) was sufficient after only testing t = 1 (which gives an integer). A second case — t = 2 — reveals the statement is insufficient.
**mistake_c:** Required both statements, missing that Statement (2) alone settles the question with a consistent YES.
**mistake_d:** Concluded each statement alone is sufficient without catching Statement (1)'s inconsistency across values of t.
**mistake_e:** Concluded together insufficient despite Statement (2) providing a definitive YES for every valid n.
**common_trap:** In yes/no DS problems, sufficiency requires the answer to be consistent for every value permitted by the statement, not just the first easy case. Statement (1) looks clean at t = 1 but breaks at t = 2.
**takeaway:** Test at least two values for each DS statement in "is expression an integer?" problems. Sufficiency means consistent across ALL valid inputs, not just the initial case.

## Q39
**difficulty:** Hard
**type:** Data Sufficiency
**topic:** Sign Analysis with Exponents

Is x^3 > x^4?

(1) x < 1
(2) x > −1

- A) Statement (1) ALONE is sufficient, but statement (2) alone is not sufficient.
- B) Statement (2) ALONE is sufficient, but statement (1) alone is not sufficient.
- C) BOTH statements TOGETHER are sufficient, but NEITHER statement ALONE is sufficient.
- D) EACH statement ALONE is sufficient.
- E) Statements (1) and (2) TOGETHER are NOT sufficient.

**answer:** E
**fastest_path:** x^3 > x^4 iff 0 < x < 1. Together, −1 < x < 1: try x = 0.5 (YES) and x = −0.5 (NO). Still inconsistent → E.
**explanation:** First find when x^3 > x^4 holds. Rearrange: x^3 − x^4 = x^3(1 − x) > 0. This holds when x^3 and (1 − x) share the same sign. Both positive: x > 0 and x < 1 → 0 < x < 1. Both negative: x < 0 and x > 1 → impossible. So x^3 > x^4 if and only if 0 < x < 1.

Statement (1): x < 1. Test x = 0.5 (in (0,1) → YES) and x = −2 [(−2)^3 = −8 and (−2)^4 = 16, so −8 > 16? NO]. Different answers → insufficient.

Statement (2): x > −1. Test x = 0.5 (YES) and x = 2 [8 > 16? NO]. Different answers → insufficient.

Together: −1 < x < 1. Test x = 0.5 (YES) and x = −0.5 [(−0.5)^3 = −0.125 and (−0.5)^4 = 0.0625, so −0.125 > 0.0625? NO]. Still different answers → insufficient. Answer: E.
**mistake_a:** Concluded Statement (1) sufficient by testing only x = 0.5 without checking negative values less than −1.
**mistake_b:** Concluded Statement (2) sufficient by testing only x = 0.5 without checking x = 2.
**mistake_c:** Thought combining the constraints would eliminate ambiguity — but the interval (−1, 0) satisfies both statements yet still fails the inequality.
**mistake_d:** Concluded each statement alone is sufficient without finding counterexamples to either one.
**common_trap:** Assuming that keeping x between −1 and 1 forces x to be positive. The interval (−1, 0) is within (−1, 1) but makes x^3 < 0 < x^4, so the inequality fails. Never assume a bounded interval avoids sign issues without checking the full range.
**takeaway:** Factor first: x^3 − x^4 = x^3(1−x). Sign analysis pinpoints the exact condition (0 < x < 1). Then verify whether each statement, alone or together, guarantees that condition for every allowed value of x.

## Q40
**difficulty:** Hard
**type:** Problem Solving
**topic:** Exponent Rules

If 12^n = 2^a × 3^b, where n, a, and b are positive integers, which of the following must be true?

- A) a = b
- B) a = 2b
- C) b = 2a
- D) a + b = 4n
- E) a = 3n

**answer:** B
**fastest_path:** 12 = 2² × 3 → 12^n = 2^(2n) × 3^n → a = 2n, b = n → a = 2b. ✓
**explanation:** Prime-factor 12: 12 = 4 × 3 = 2² × 3. Then 12^n = (2² × 3)^n = (2²)^n × 3^n = 2^(2n) × 3^n. So a = 2n and b = n. Check each option:
A) a = b → 2n = n — false for any positive n.
B) a = 2b → 2n = 2(n) = 2n — TRUE for all positive n.
C) b = 2a → n = 2(2n) = 4n — false for any positive n.
D) a + b = 4n → 2n + n = 3n ≠ 4n — false.
E) a = 3n → 2n = 3n — false for any positive n.
**mistake_a:** Confused the prime factorization of 12, assuming both prime exponents come out equal.
**mistake_c:** Reversed the relationship — b = n is half of a = 2n, not double.
**mistake_d:** Mis-added a + b = 2n + n = 3n and confused this with 4n. Off by one factor of n.
**mistake_e:** Mistook 12 = 2³ × something (wrong) — the correct factorization is 12 = 2² × 3, giving a = 2n, not 3n.
**common_trap:** Forgetting to distribute the outer exponent n to every prime factor. 12^n is not 2² × 3^n — the exponent n must be applied to both prime factors: (2²)^n × 3^n = 2^(2n) × 3^n.
**takeaway:** To find the prime factorization of a compound base raised to a power: first factor the base (12 = 2² × 3), then distribute the outer exponent to each prime via power-of-a-product: (2² × 3)^n = 2^(2n) × 3^n.

## Q41
**difficulty:** Hard
**type:** Problem Solving
**topic:** Exponent Properties

If a and b are positive integers with a < b, a^b = b^a, and a + b < 10, what is the value of b − a?

- A) 1
- B) 2
- C) 3
- D) 4
- E) 5

**answer:** B
**fastest_path:** Test small pairs: (2, 3) — 8 ≠ 9. (2, 4) — 2^4 = 16, 4^2 = 16. Equal! a + b = 6 < 10. b − a = 2.
**explanation:** Search systematically for positive integer pairs (a, b) with a < b, a^b = b^a, and a + b < 10.
a = 2: b = 3: 2^3 = 8, 3^2 = 9. Not equal. b = 4: 2^4 = 16, 4^2 = 16. Equal, and 2 + 4 = 6 < 10. b − a = 2.
b = 5: 2^5 = 32, 5^2 = 25. Not equal. b = 6: 2^6 = 64, 6^2 = 36. Not equal.
a = 3: b = 4: 3^4 = 81, 4^3 = 64. Not equal. b = 5: 3^5 = 243, 5^3 = 125. Not equal. b = 6: a + b = 9 < 10 but 3^6 = 729, 6^3 = 216. Not equal.
The unique solution is (a, b) = (2, 4), giving b − a = 2.
Why does (2, 4) work? Because 4 = 2². Then 2^4 = 16 and 4^2 = (2²)^2 = 2^4 = 16. In general, when b = a², a^b = a^(a²) and b^a = (a²)^a = a^(2a); these are equal when a² = 2a, which gives a = 2 as the only positive integer solution greater than 1.
**mistake_a:** Testing (2, 3): 2^3 = 8, 3^2 = 9. Not equal; difference 1 does not work.
**mistake_c:** Testing (2, 5): 32 ≠ 25, or (3, 6): 3^6 = 729 ≠ 6^3 = 216. Difference 3 does not work.
**mistake_d:** Testing (2, 6): 64 ≠ 36, or (3, 7): a + b = 10, out of range. Difference 4 does not work.
**mistake_e:** Testing (2, 7): 128 ≠ 49. Difference 5 does not work.
**common_trap:** Assuming a larger gap between a and b makes equality more likely, or abandoning the search after (2, 3) fails. The equation a^b = b^a is highly restrictive — the only integer pair satisfying it with a < b and small values is (2, 4).
**takeaway:** For exotic equations like a^b = b^a, systematic small-case testing is more reliable than algebraic manipulation. The pair (2, 4) is the unique positive-integer solution with a < b, rooted in the identity 2^4 = (2²)^2 = 4^2.
**related_reading:** reading-quant-03-number-properties
