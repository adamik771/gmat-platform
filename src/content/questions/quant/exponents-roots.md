## Q1
**difficulty:** Easy
**type:** Problem Solving
**topic:** Exponent Rules

What is the value of 2⁵ * 2³?

- A) 2⁸
- B) 2¹⁵
- C) 4⁸
- D) 4¹⁵
- E) 2²

**answer:** A
**fastest_path:** Same base → add exponents: 2⁵ × 2³ = 2⁸.
**explanation:** Product of same-base powers: a^m × a^n = a^(m+n). So 2⁵ × 2³ = 2^(5+3) = 2⁸. The base stays at 2; only the exponents combine.
**mistake_b:** Multiplied exponents: 5 × 3 = 15 → 2¹⁵.
**mistake_c:** Multiplied bases: 2 × 2 = 4, then added exponents → 4⁸.
**mistake_d:** Multiplied bases AND exponents → 4¹⁵.
**mistake_e:** Subtracted exponents instead of adding → 2².
**common_trap:** Multiplying the bases as well as the exponents.
**takeaway:** Same base, multiplication: add exponents (a^m × a^n = a^(m+n)). The base never changes during this operation.

## Q2
**difficulty:** Easy
**type:** Problem Solving
**topic:** Roots & Radicals

Simplify √50.

- A) 5
- B) 5*√2
- C) 2*√5
- D) 10*√5
- E) 25*√2

**answer:** B
**fastest_path:** 50 = 25 × 2 → √50 = 5√2.
**explanation:** Pull out the largest perfect-square factor. 50 = 25 × 2. So √50 = √25 × √2 = 5√2.
**mistake_a:** Computed only √25 = 5 (forgot the √2).
**mistake_c:** Reversed factor placement: 2√5 from 50 = 4 × 12.5 (incorrect setup).
**mistake_d:** Misfactored as 100 × 0.5; got 10√5.
**mistake_e:** Pulled out 2 instead of 25; got 25√2 (squared the wrong factor).
**common_trap:** Pulling out the smaller factor (e.g., √2) instead of the largest perfect square.
**takeaway:** To simplify √n, factor n into (perfect square × remaining). Memorize perfect squares: 4, 9, 16, 25, 36, 49, 64, 81, 100.

**topic:** Exponent Rules

What is the value of 3⁻²?

- A) -9
- B) -6
- C) -1/9

**answer:** E

**mistake_a:** Treated 3⁻² as −(3²) = −9.

**mistake_c:** Got the reciprocal but kept the negative: −1/9.
**mistake_d:** Computed 1/(3 × 2) = 1/6 (multiplied base × exponent in denominator).
**common_trap:** Treating negative exponents as making the result negative.
**takeaway:** a⁻ⁿ = 1/aⁿ. Negative exponents flip into denominators; they never produce negative values from positive bases.

## Q6
**difficulty:** Medium
**type:** Problem Solving
**topic:** Exponent Rules

Which of the following equals (x⁴ * y⁻²) / (x⁻¹ * y³)?

- A) x³ * y⁻⁵
- B) x⁵ * y⁻⁵
- C) x⁵ * y⁻¹
- D) x³ * y⁻¹
- E) x⁵ * y

**answer:** B
**fastest_path:** Subtract exponents: x^(4−(−1)) × y^(−2−3) = x⁵ × y⁻⁵.
**explanation:** Same-base division: a^m / a^n = a^(m−n). For x: 4 − (−1) = 5 → x⁵. For y: (−2) − 3 = −5 → y⁻⁵. Result: x⁵ × y⁻⁵.
**mistake_a:** x: 4 − 1 = 3 (forgot the double-negative).
**mistake_c:** y: −2 + 3 = 1 (added instead of subtracted), got y⁻¹.
**mistake_d:** Both errors: x³ and y⁻¹.
**mistake_e:** y exponent: subtracted wrong way, got y⁺¹.
**common_trap:** Mishandling double-negatives — subtracting a negative is *adding*.
**takeaway:** a^m / a^n = a^(m−n). When the denominator's exponent is negative, the subtraction becomes addition (m − (−n) = m + n).
**related_reading:** reading-quant-04-algebra-and-equations

## Q7
**difficulty:** Medium
**type:** Problem Solving
**topic:** Roots & Radicals

Simplify √12 + √27.

- A) √39
- B) 3*√13
- C) 5*√3
- D) 6*√3
- E) 13*√3

**answer:** C
**fastest_path:** Simplify: √12 = 2√3, √27 = 3√3. Sum = 5√3.
**explanation:** Radicals only add when they share the same radicand. Simplify each: √12 = √(4 × 3) = 2√3; √27 = √(9 × 3) = 3√3. Both share √3, so add coefficients: 2√3 + 3√3 = 5√3.
**mistake_a:** Computed √(12 + 27) = √39 (cannot add radicands inside one root).
**mistake_b:** Computed wrong simplification; got 3√13.
**mistake_d:** Coefficient addition slip: 2 + 3 = 6 instead of 5.
**mistake_e:** Added radicands and coefficients: (2+3)√(12+27) → 5√39 (wrong); rounded.
**common_trap:** Adding inside the radical (√a + √b ≠ √(a + b)) — this is one of the most common mistakes.
**takeaway:** Add radicals only after simplifying to matching radicands. √a + √b = √(a + b) is *false*; treat radicals like variables — only add when they're the same "kind."
**related_reading:** reading-quant-04-algebra-and-equations

## Q8
**difficulty:** Medium
**type:** Problem Solving
**topic:** Fractional Exponents

What is the value of 27^(2/3)?

- A) 3
- B) 6
- C) 9
- D) 18
- E) 81

**answer:** C
**fastest_path:** 27^(2/3) = (27^(1/3))² = 3² = 9.
**explanation:** Fractional exponent rule: a^(m/n) = (a^(1/n))^m. So 27^(2/3) = (27^(1/3))² = 3² = 9. Take the root first (smaller numbers); raising to the power second.
**mistake_a:** Computed 27^(1/3) = 3 and stopped (didn't square).
**mistake_b:** Computed 27 × 2/3 = 18, halved to ~6.
**mistake_d:** Computed 27 × 2/3 = 18.
**mistake_e:** Computed 27² / 3 = 729/3 = 243 (raised to 2 first, then divided by 3 — wrong).
**common_trap:** Treating a^(m/n) as a × m/n or as a^m / n.
**takeaway:** a^(m/n) = (a^(1/n))^m = (n-th root of a) raised to m. Take root first when n divides cleanly; small numbers are easier.
**related_reading:** reading-quant-04-algebra-and-equations

**topic:** Exponent Rules

If (2^a)³ = 2¹², what is a?

**common_trap:** Confusing (a^m)^n = a^(mn) with a^m × a^n = a^(m+n).
**takeaway:** Power of a power → multiply: (a^m)^n = a^(mn). Different from same-base product (add exponents). Memorize both.

## Q12
**difficulty:** Hard
**type:** Problem Solving
**topic:** Roots & Radicals

Rationalize the denominator: 6 / (√3 + 1).

- A) 6*√3 - 6
- B) 3*√3 - 3
- C) 3*√3 + 3
- D) 2*√3 + 2
- E) √3 - 1

**answer:** B
**fastest_path:** Multiply by conjugate (√3 − 1)/(√3 − 1): denom = 3 − 1 = 2; numer = 6(√3 − 1)/2 = 3√3 − 3.
**explanation:** To clear a sum/difference with a radical in the denominator, multiply by the *conjugate* (flip the sign between terms). Numerator: 6 × (√3 − 1) = 6√3 − 6. Denominator: (√3 + 1)(√3 − 1) = 3 − 1 = 2 (difference of squares). Result: (6√3 − 6)/2 = 3√3 − 3.
**mistake_a:** Computed 6(√3 − 1) without dividing by 2.
**mistake_c:** Used the same sign instead of conjugate.
**mistake_d:** Divided by 3 instead of 2; got 2√3 − 2.
**mistake_e:** Cancelled too aggressively; got √3 − 1.
**common_trap:** Forgetting to use the conjugate's flipped sign — multiplying by (√3 + 1)/(√3 + 1) doesn't clear the radical.
**takeaway:** Rationalize sums/differences with radicals using the *conjugate*: (a + b)(a − b) = a² − b². The result has no radical in the denominator.
**related_reading:** reading-quant-04-algebra-and-equations

## Q18
**difficulty:** Hard
**type:** Data Sufficiency
**topic:** Sign Analysis with Exponents

Is x > 0?

(1) x⁵ > 0.
(2) x² < x.

- A) Statement (1) ALONE is sufficient, but statement (2) alone is not sufficient.
- B) Statement (2) ALONE is sufficient, but statement (1) alone is not sufficient.
- C) BOTH statements TOGETHER are sufficient, but NEITHER statement ALONE is sufficient.
- D) EACH statement ALONE is sufficient.
- E) Statements (1) and (2) TOGETHER are NOT sufficient.

**answer:** D
**fastest_path:** (1) Odd power preserves sign: x⁵ > 0 → x > 0. (2) x² < x → 0 < x < 1 → x > 0. Both alone sufficient → D.
**explanation:** Statement (1): x⁵ > 0. Odd powers preserve sign — if x were negative, x⁵ would be negative. So x > 0. Sufficient.

Statement (2): x² < x rearranges to x − x² > 0 → x(1 − x) > 0. This holds when x and (1 − x) have the same sign. Both positive: 0 < x < 1. Both negative: x < 0 AND x > 1 (impossible). So 0 < x < 1, which is x > 0. Sufficient.

Each alone works → D.
**mistake_a:** Concluded only Statement 1 sufficient, missed Statement 2's resolution.
**mistake_b:** Concluded only Statement 2 sufficient.
**mistake_c:** Required both statements.
**mistake_e:** Concluded together insufficient.
**common_trap:** Assuming Statement 2 admits negative x without checking the sign diagram.
**takeaway:** Odd powers preserve sign (x⁵ > 0 ⟺ x > 0). For x² < x, factor: x(1 − x) > 0 → 0 < x < 1 (both positive case).
**related_reading:** reading-di-02-data-sufficiency-logic

All three are now raised to the 10th power, so compare the bases only: 6 < 8 < 9. Since all bases are positive and the exponent is the same, larger base → larger value. Order: 6^10 < 8^10 < 9^10, i.e., 6^10 < 2^30 < 3^20.
**mistake_b:** 2^30 < 6^10 — ranked 2^30 below 6^10 by comparing bases (2 < 6) without adjusting for the much larger exponent of 30 vs 10.
**mistake_c:** 2^30 > 3^20 — ranked 2^30 highest because it has the largest exponent (30 > 20), ignoring that the base 2 < 3.
**mistake_d:** Reversed all three — compared bases without regard to exponents.
**mistake_e:** 6^10 > 3^20 > 2^30 — ranked by base size alone (6 > 3 > 2) without adjusting exponents.
**common_trap:** Comparing by exponent alone (30 > 20 > 10 suggests 2^30 is largest) or by base alone (6 > 3 > 2 suggests 6^10 is largest). Neither is correct — you must normalize the exponent first.
**takeaway:** To compare expressions with different bases and exponents, convert to a common exponent using power of a power. Once exponents match, larger base = larger value (for positive bases > 1).

## Q38
**difficulty:** Hard
**type:** Data Sufficiency
**topic:** Sign Analysis with Exponents

Is x^m positive?

(1) x < 0
(2) m is even

- A) Statement (1) ALONE is sufficient, but statement (2) alone is not sufficient.
- B) Statement (2) ALONE is sufficient, but statement (1) alone is not sufficient.
- C) BOTH statements TOGETHER are sufficient, but NEITHER statement ALONE is sufficient.
- D) EACH statement ALONE is sufficient.
- E) Statements (1) and (2) TOGETHER are NOT sufficient.

**answer:** C
**fastest_path:** (1) x < 0 alone: if m is odd → negative (no); if m is even → positive (yes). Insufficient. (2) m even alone: if x = 0 → 0^m = 0 (not positive). If x ≠ 0 → positive (yes). Insufficient. Together: x < 0 and m even → x^m = (negative)^(even) > 0. Yes, definitively. → C.
**explanation:** Statement (1): x < 0. If m is even, x^m > 0 (yes). If m is odd, x^m < 0 (no). The result depends on m, which we don't know. Insufficient.

Statement (2): m is even. If x ≠ 0, then x^m = (x²)^(m/2) > 0 (yes). But if x = 0, then 0^m = 0, which is not positive (no). We can't rule out x = 0. Insufficient.

Together: x < 0 guarantees x ≠ 0 (eliminating the x = 0 edge case from statement 2), and m is even guarantees the result is positive. Together: YES definitively. Sufficient.
**mistake_a:** Concluded only (1) sufficient — forgot that odd m makes x^m negative when x < 0.
**mistake_b:** Concluded only (2) sufficient — missed the x = 0 edge case (0^m = 0, which is not positive).
**mistake_d:** Concluded each alone sufficient — made both errors A and B simultaneously.
**mistake_e:** Concluded together insufficient — thought some ambiguity remains even with both conditions.
**common_trap:** Forgetting that x = 0 is a valid value not ruled out by "m is even." Zero is neither positive nor negative, so 0^(even) = 0 fails the "is positive" test.
**takeaway:** In DS sign questions involving exponents, always test three cases for the base: positive, negative, and zero. Zero is the most frequently overlooked case. A statement combining "x < 0" with "m is even" is the classic sufficient pair for x^m > 0.

## Q39
**difficulty:** Hard
**type:** Problem Solving
**topic:** Absolute Value and Even Exponents

How many real values of x satisfy x² = √(x²)?

- A) x = 0 only
- B) x = 0 and x = 1 only
- C) x = 0 and x = −1 only
- D) x = −1, x = 0, and x = 1
- E) All real numbers

**answer:** D
**fastest_path:** √(x²) = |x|. Equation: x² = |x|. Case x ≥ 0: x² = x → x(x−1) = 0 → x = 0 or 1. Case x < 0: x² = −x → x(x+1) = 0 → x = −1. Total solutions: {−1, 0, 1}.
**explanation:** Recognize that √(x²) = |x| for all real x. The equation becomes x² = |x|.

Case 1 — x ≥ 0: |x| = x, so x² = x → x² − x = 0 → x(x − 1) = 0 → x = 0 or x = 1. Both satisfy x ≥ 0. ✓

Case 2 — x < 0: |x| = −x, so x² = −x → x² + x = 0 → x(x + 1) = 0 → x = 0 or x = −1. Only x = −1 satisfies x < 0. ✓

Complete solution set: {−1, 0, 1}.

Verify each: x = −1: (−1)² = 1; √(1) = 1. ✓ x = 0: 0 = 0. ✓ x = 1: 1 = 1. ✓ x = 2: 4 ≠ 2. ✗
**mistake_a:** x = 0 only — solved only the case x² − x = 0 and took only x = 0 (missed x = 1 and x = −1).
**mistake_b:** x = 0 and x = 1 — solved the x ≥ 0 case correctly but forgot to analyze x < 0.
**mistake_c:** x = 0 and x = −1 — solved x < 0 case but missed the x = 1 solution from the x ≥ 0 case.
**mistake_e:** All real numbers — incorrectly squared both sides to get x⁴ = x², concluded it factors as x²(x²−1) = 0 giving more solutions, or simply assumed the equation must be an identity.
**common_trap:** Forgetting that √(x²) is not simply x — it equals |x|. Treating √(x²) = x misses the case when x is negative.
**takeaway:** √(x²) = |x|, not x. This is the definition of the square root — it always returns a non-negative result. When solving equations involving √(x²), split into x ≥ 0 and x < 0 cases.

## Q40
**difficulty:** Hard
**type:** Problem Solving
**topic:** Fractional Exponent Simplification

If a > 0 and b > 0, which of the following equals (a^(1/2) · b^(1/3))^6?

- A) a³b²
- B) a³b³
- C) 6a^(1/2)b^(1/3)
- D) a^6b^6
- E) a^(1/12)b^(1/18)

**answer:** A
**hint_nudge:** Apply the outer exponent to each factor separately using the power of a product rule.
**hint_strategy:** (x^p · y^q)^n = x^(pn) · y^(qn). Multiply each fractional exponent by 6.
**fastest_path:** a^(1/2 × 6) · b^(1/3 × 6) = a³ · b² = a³b².
**explanation:** Apply power of a product: (a^(1/2) · b^(1/3))^6 = a^(1/2 · 6) · b^(1/3 · 6) = a^(6/2) · b^(6/3) = a³ · b². The outer exponent multiplies each interior exponent: 1/2 × 6 = 3, and 1/3 × 6 = 2.
**mistake_b:** a³b³ — applied 6/2 = 3 to both variables, ignoring that b's interior exponent is 1/3 (so 1/3 × 6 = 2, not 3).
**mistake_c:** 6a^(1/2)b^(1/3) — multiplied by 6 as a coefficient instead of raising to the 6th power.
**mistake_d:** a^6b^6 — dropped the fractional exponents and applied 6 to base factors directly: a^(1·6) · b^(1·6) = a^6b^6.
**mistake_e:** a^(1/12)b^(1/18) — divided the fractional exponents by 6 instead of multiplying: (1/2)/6 = 1/12 and (1/3)/6 = 1/18.
**common_trap:** Treating the interior exponents as 1 (and applying the outer exponent as if the bases were simply a and b, not a^(1/2) and b^(1/3)), giving a^6b^6.
**takeaway:** (a^p · b^q)^n = a^(pn) · b^(qn). Multiply interior exponents by the outer exponent — whether interior exponents are whole numbers, fractions, or negatives.

## Q41
**difficulty:** Challenge
**type:** Problem Solving
**topic:** Divisibility with Exponential Expressions

For how many positive integer values of n does (2^n + 1) divide evenly into (2^(n+2) + 1)?

- A) 0
- B) 1
- C) 2
- D) 3
- E) Infinitely many

**answer:** B
**fastest_path:** 2^(n+2) + 1 = 4·2^n + 1 = 4(2^n + 1) − 3. So (2^n + 1) | (2^(n+2) + 1) requires (2^n + 1) | 3. Since 2^n + 1 ≥ 3 for n ≥ 1, need 2^n + 1 = 3 → n = 1. Exactly one value.
**explanation:** Rewrite the numerator in terms of (2^n + 1):
2^(n+2) + 1 = 4 · 2^n + 1 = 4(2^n + 1) − 4 + 1 = 4(2^n + 1) − 3.

For (2^n + 1) to divide 2^(n+2) + 1, it must divide the remainder −3, i.e., (2^n + 1) | 3.

The positive divisors of 3 are 1 and 3. Since 2^n ≥ 2 for all positive integers n, we have 2^n + 1 ≥ 3. So the only possibility is 2^n + 1 = 3, giving 2^n = 2, hence n = 1.

Verify n = 1: 2^1 + 1 = 3; 2^3 + 1 = 9; 9 ÷ 3 = 3. ✓ Divides evenly.
Check n = 2: 2^2 + 1 = 5; 2^4 + 1 = 17; 17 ÷ 5 = 3.4. ✗
Check n = 3: 2^3 + 1 = 9; 2^5 + 1 = 33; 33 ÷ 9 = 3.67. ✗

Exactly one value works: n = 1.
**mistake_a:** 0 — checked n = 2 and n = 3, found neither worked, and didn't check n = 1 (or discarded n = 1 by mistakenly verifying 9/3 incorrectly).
**mistake_c:** 2 — found n = 1 and assumed n = 0 also qualifies; but n must be a positive integer (n = 0 is excluded).
**mistake_d:** 3 — guessed n = 1, 2, 3 all work without computing; or made an arithmetic error on n = 2 and n = 3.
**mistake_e:** Infinitely many — sensed a pattern ("2^n + 1 always divides something") without testing specific cases.
**common_trap:** Testing only n = 2 and n = 3 (and finding they fail), then concluding no values work. The simplest case n = 1 is the one that works and must be checked first.
**takeaway:** When asked "for how many values does X divide Y?", rewrite Y as a multiple of X plus a remainder: Y = q·X + r. Then X | Y iff X | r. This reduces an exponential divisibility problem to finding which values of X divide the (often small) remainder r.
**related_reading:** reading-quant-03-number-properties
