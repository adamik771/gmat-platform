## Q1
**difficulty:** Easy
**type:** Problem Solving
**topic:** Exponent Rules

What is the value of 2⁵ * 2³?

- A) 2⁸
- B) 2¹⁵
- C) 4⁸
- D) 4¹⁵
- E) 2²

**answer:** A
**fastest_path:** Same base → add exponents: 2⁵ × 2³ = 2⁸.
**explanation:** Product of same-base powers: a^m × a^n = a^(m+n). So 2⁵ × 2³ = 2^(5+3) = 2⁸. The base stays at 2; only the exponents combine.
**mistake_b:** Multiplied exponents: 5 × 3 = 15 → 2¹⁵.
**mistake_c:** Multiplied bases: 2 × 2 = 4, then added exponents → 4⁸.
**mistake_d:** Multiplied bases AND exponents → 4¹⁵.
**mistake_e:** Subtracted exponents instead of adding → 2².
**common_trap:** Multiplying the bases as well as the exponents.
**takeaway:** Same base, multiplication: add exponents (a^m × a^n = a^(m+n)). The base never changes during this operation.

## Q2
**difficulty:** Easy
**type:** Problem Solving
**topic:** Roots & Radicals

Simplify √50.

- A) 5
- B) 5*√2
- C) 2*√5
- D) 10*√5
- E) 25*√2

**answer:** B
**fastest_path:** 50 = 25 × 2 → √50 = 5√2.
**explanation:** Pull out the largest perfect-square factor. 50 = 25 × 2. So √50 = √25 × √2 = 5√2.
**mistake_a:** Computed only √25 = 5 (forgot the √2).
**mistake_c:** Reversed factor placement: 2√5 from 50 = 4 × 12.5 (incorrect setup).
**mistake_d:** Misfactored as 100 × 0.5; got 10√5.
**mistake_e:** Pulled out 2 instead of 25; got 25√2 (squared the wrong factor).
**common_trap:** Pulling out the smaller factor (e.g., √2) instead of the largest perfect square.
**takeaway:** To simplify √n, factor n into (perfect square × remaining). Memorize perfect squares: 4, 9, 16, 25, 36, 49, 64, 81, 100.

**topic:** Exponent Rules

What is the value of 3⁻²?

- A) -9
- B) -6
- C) -1/9

**answer:** E

**mistake_a:** Treated 3⁻² as −(3²) = −9.

**mistake_c:** Got the reciprocal but kept the negative: −1/9.
**mistake_d:** Computed 1/(3 × 2) = 1/6 (multiplied base × exponent in denominator).
**common_trap:** Treating negative exponents as making the result negative.
**takeaway:** a⁻ⁿ = 1/aⁿ. Negative exponents flip into denominators; they never produce negative values from positive bases.

## Q6
**difficulty:** Medium
**type:** Problem Solving
**topic:** Exponent Rules

Which of the following equals (x⁴ * y⁻²) / (x⁻¹ * y³)?

- A) x³ * y⁻⁵
- B) x⁵ * y⁻⁵
- C) x⁵ * y⁻¹
- D) x³ * y⁻¹
- E) x⁵ * y

**answer:** B
**fastest_path:** Subtract exponents: x^(4−(−1)) × y^(−2−3) = x⁵ × y⁻⁵.
**explanation:** Same-base division: a^m / a^n = a^(m−n). For x: 4 − (−1) = 5 → x⁵. For y: (−2) − 3 = −5 → y⁻⁵. Result: x⁵ × y⁻⁵.
**mistake_a:** x: 4 − 1 = 3 (forgot the double-negative).
**mistake_c:** y: −2 + 3 = 1 (added instead of subtracted), got y⁻¹.
**mistake_d:** Both errors: x³ and y⁻¹.
**mistake_e:** y exponent: subtracted wrong way, got y⁺¹.
**common_trap:** Mishandling double-negatives — subtracting a negative is *adding*.
**takeaway:** a^m / a^n = a^(m−n). When the denominator's exponent is negative, the subtraction becomes addition (m − (−n) = m + n).
**related_reading:** reading-quant-04-algebra-and-equations

## Q7
**difficulty:** Medium
**type:** Problem Solving
**topic:** Roots & Radicals

Simplify √12 + √27.

- A) √39
- B) 3*√13
- C) 5*√3
- D) 6*√3
- E) 13*√3

**answer:** C
**fastest_path:** Simplify: √12 = 2√3, √27 = 3√3. Sum = 5√3.
**explanation:** Radicals only add when they share the same radicand. Simplify each: √12 = √(4 × 3) = 2√3; √27 = √(9 × 3) = 3√3. Both share √3, so add coefficients: 2√3 + 3√3 = 5√3.
**mistake_a:** Computed √(12 + 27) = √39 (cannot add radicands inside one root).
**mistake_b:** Computed wrong simplification; got 3√13.
**mistake_d:** Coefficient addition slip: 2 + 3 = 6 instead of 5.
**mistake_e:** Added radicands and coefficients: (2+3)√(12+27) → 5√39 (wrong); rounded.
**common_trap:** Adding inside the radical (√a + √b ≠ √(a + b)) — this is one of the most common mistakes.
**takeaway:** Add radicals only after simplifying to matching radicands. √a + √b = √(a + b) is *false*; treat radicals like variables — only add when they're the same "kind."
**related_reading:** reading-quant-04-algebra-and-equations

## Q8
**difficulty:** Medium
**type:** Problem Solving
**topic:** Fractional Exponents

What is the value of 27^(2/3)?

- A) 3
- B) 6
- C) 9
- D) 18
- E) 81

**answer:** C
**fastest_path:** 27^(2/3) = (27^(1/3))² = 3² = 9.
**explanation:** Fractional exponent rule: a^(m/n) = (a^(1/n))^m. So 27^(2/3) = (27^(1/3))² = 3² = 9. Take the root first (smaller numbers); raising to the power second.
**mistake_a:** Computed 27^(1/3) = 3 and stopped (didn't square).
**mistake_b:** Computed 27 × 2/3 = 18, halved to ~6.
**mistake_d:** Computed 27 × 2/3 = 18.
**mistake_e:** Computed 27² / 3 = 729/3 = 243 (raised to 2 first, then divided by 3 — wrong).
**common_trap:** Treating a^(m/n) as a × m/n or as a^m / n.
**takeaway:** a^(m/n) = (a^(1/n))^m = (n-th root of a) raised to m. Take root first when n divides cleanly; small numbers are easier.
**related_reading:** reading-quant-04-algebra-and-equations

**topic:** Exponent Rules

If (2^a)³ = 2¹², what is a?

**common_trap:** Confusing (a^m)^n = a^(mn) with a^m × a^n = a^(m+n).
**takeaway:** Power of a power → multiply: (a^m)^n = a^(mn). Different from same-base product (add exponents). Memorize both.

## Q12
**difficulty:** Hard
**type:** Problem Solving
**topic:** Roots & Radicals

Rationalize the denominator: 6 / (√3 + 1).

- A) 6*√3 - 6
- B) 3*√3 - 3
- C) 3*√3 + 3
- D) 2*√3 + 2
- E) √3 - 1

**answer:** B
**fastest_path:** Multiply by conjugate (√3 − 1)/(√3 − 1): denom = 3 − 1 = 2; numer = 6(√3 − 1)/2 = 3√3 − 3.
**explanation:** To clear a sum/difference with a radical in the denominator, multiply by the *conjugate* (flip the sign between terms). Numerator: 6 × (√3 − 1) = 6√3 − 6. Denominator: (√3 + 1)(√3 − 1) = 3 − 1 = 2 (difference of squares). Result: (6√3 − 6)/2 = 3√3 − 3.
**mistake_a:** Computed 6(√3 − 1) without dividing by 2.
**mistake_c:** Used the same sign instead of conjugate.
**mistake_d:** Divided by 3 instead of 2; got 2√3 − 2.
**mistake_e:** Cancelled too aggressively; got √3 − 1.
**common_trap:** Forgetting to use the conjugate's flipped sign — multiplying by (√3 + 1)/(√3 + 1) doesn't clear the radical.
**takeaway:** Rationalize sums/differences with radicals using the *conjugate*: (a + b)(a − b) = a² − b². The result has no radical in the denominator.
**related_reading:** reading-quant-04-algebra-and-equations

## Q18
**difficulty:** Hard
**type:** Data Sufficiency
**topic:** Sign Analysis with Exponents

Is x > 0?

(1) x⁵ > 0.
(2) x² < x.

- A) Statement (1) ALONE is sufficient, but statement (2) alone is not sufficient.
- B) Statement (2) ALONE is sufficient, but statement (1) alone is not sufficient.
- C) BOTH statements TOGETHER are sufficient, but NEITHER statement ALONE is sufficient.
- D) EACH statement ALONE is sufficient.
- E) Statements (1) and (2) TOGETHER are NOT sufficient.

**answer:** D
**fastest_path:** (1) Odd power preserves sign: x⁵ > 0 → x > 0. (2) x² < x → 0 < x < 1 → x > 0. Both alone sufficient → D.
**explanation:** Statement (1): x⁵ > 0. Odd powers preserve sign — if x were negative, x⁵ would be negative. So x > 0. Sufficient.

Statement (2): x² < x rearranges to x − x² > 0 → x(1 − x) > 0. This holds when x and (1 − x) have the same sign. Both positive: 0 < x < 1. Both negative: x < 0 AND x > 1 (impossible). So 0 < x < 1, which is x > 0. Sufficient.

Each alone works → D.
**mistake_a:** Concluded only Statement 1 sufficient, missed Statement 2's resolution.
**mistake_b:** Concluded only Statement 2 sufficient.
**mistake_c:** Required both statements.
**mistake_e:** Concluded together insufficient.
**common_trap:** Assuming Statement 2 admits negative x without checking the sign diagram.
**takeaway:** Odd powers preserve sign (x⁵ > 0 ⟺ x > 0). For x² < x, factor: x(1 − x) > 0 → 0 < x < 1 (both positive case).
**related_reading:** reading-di-02-data-sufficiency-logic

## Q37
**difficulty:** Hard
**type:** Problem Solving
**topic:** Variable Exponents with Different Bases

If 4^x = 8^y and neither x nor y is zero, what is the value of x/y?

- A) 1/2
- B) 2/3
- C) 3/2
- D) 2
- E) 3

**fastest_path:** Convert to base 2: 2^(2x) = 2^(3y) → 2x = 3y → x/y = 3/2.
**explanation:** Express both sides using the smallest common base, which is 2. Since 4 = 2² and 8 = 2³: 4^x = (2²)^x = 2^(2x) and 8^y = (2³)^y = 2^(3y). The equation becomes 2^(2x) = 2^(3y). Same base, equal: 2x = 3y. Solving for x/y: x/y = 3/2.
**mistake_a:** Took the ratio of the original base values: 4/8 = 1/2. This confuses base ratios with exponent ratios — two very different things.
**mistake_b:** Set up 2x = 3y correctly but solved for y/x = 2/3 instead of x/y = 3/2 — inverted the target ratio.
**mistake_d:** Mis-converted bases: perhaps 4 = 2¹ and 8 = 2², giving 2^x = 2^(2y) → x/y = 2. The correct prime exponents are 2 for 4 and 3 for 8.
**mistake_e:** Used the literal base ratio 8/4 = 2, then added 1 (from some confused reasoning) to get 3.
**common_trap:** skipping-base-conversion — attempting to compare 4^x and 8^y without converting both to base 2. Without a common base, you cannot equate exponents.
**takeaway:** When bases differ but share a common prime factor, convert all terms to that prime base. Then equate exponents. Pattern: (2^a)^x = (2^b)^y → ax = by → x/y = b/a. This technique solves most GMAT "different base" exponent problems.

## Q38
**difficulty:** Hard
**type:** Data Sufficiency
**topic:** Sign Analysis with Exponents

If n is an integer with n ≥ 2, is a^n > a?

(1) a > 1
(2) a is an integer and a ≥ 0

- A) Statement (1) ALONE is sufficient, but statement (2) alone is not sufficient.
- B) Statement (2) ALONE is sufficient, but statement (1) alone is not sufficient.
- C) BOTH statements TOGETHER are sufficient, but NEITHER statement ALONE is sufficient.
- D) EACH statement ALONE is sufficient.
- E) Statements (1) and (2) TOGETHER are NOT sufficient.

**answer:** A
**fastest_path:** (1) a > 1: multiplying by a > 1 increases, so a^n > a. Always YES. Sufficient. (2) a ≥ 0 integer: a = 0 → 0 = 0, not > 0 (NO); a = 2 → YES. Inconsistent. Not sufficient.
**explanation:** Statement (1): a > 1 and n ≥ 2. a^n = a × a^(n−1). Since a > 1, the factor a^(n−1) ≥ a > 1, so a^n > a × 1 = a. The answer is always YES. Statement (1) is sufficient.

Statement (2): a is a non-negative integer. Test cases: a = 0, n = 2 → 0^2 = 0, and 0 > 0 is FALSE. a = 1, n = 2 → 1^2 = 1, and 1 > 1 is FALSE. a = 2, n = 2 → 4 > 2 is TRUE. Different answers → Statement (2) is not sufficient.

Answer: A.
**mistake_b:** Concluded Statement 2 is sufficient after testing only a = 2, n = 2 (YES), without checking boundary values a = 0 and a = 1.
**mistake_c:** Required both statements together, not recognizing that Statement 1 alone is decisive.
**mistake_d:** Claimed each alone is sufficient, missing the counterexamples a = 0 and a = 1 for Statement 2.
**mistake_e:** Concluded together insufficient — but with a > 1 and n ≥ 2, the answer is definitively YES.
**common_trap:** single-test-fallacy for Statement 2 — testing only a = 2, n = 2 (YES) and calling it sufficient, without checking the boundary values a = 0 and a = 1 that produce NO.
**takeaway:** For DS yes/no questions, a statement is sufficient only if every valid value yields the same answer. Always test boundary cases (a = 0, a = 1 for non-negative integer problems) before concluding sufficient.

## Q39
**difficulty:** Hard
**type:** Problem Solving
**topic:** Radical Algebraic Identities

What is the value of (√5 + √3)² − (√5 − √3)²?

- A) 0
- B) 2√15
- C) 4√15
- D) 16
- E) 8 + 4√15

**answer:** C
**fastest_path:** Identity: (A + B)² − (A − B)² = 4AB. Here A = √5, B = √3. Result = 4√5 · √3 = 4√15.
**explanation:** Recognize the algebraic identity: (A + B)² − (A − B)² = [(A + B) + (A − B)][(A + B) − (A − B)] = (2A)(2B) = 4AB. With A = √5 and B = √3: result = 4 · √5 · √3 = 4√15. Alternatively, expand directly: (√5 + √3)² = 5 + 2√15 + 3 = 8 + 2√15. (√5 − √3)² = 5 − 2√15 + 3 = 8 − 2√15. Difference: (8 + 2√15) − (8 − 2√15) = 4√15.
**mistake_a:** Concluded that the two expressions cancel entirely, as if √5 + √3 = √5 − √3 (which would require √3 = 0).
**mistake_b:** Identified the cross term 2√15 from the first expansion but stopped without accounting for the second expansion's −2√15, giving only 2√15 instead of the full 4√15.
**mistake_d:** Added the two squares instead of subtracting: (8 + 2√15) + (8 − 2√15) = 16. A sign error in the operation — the problem uses minus, not plus.
**mistake_e:** Computed only (√5 + √3)² = 8 + 2√15 and stopped, or failed to subtract the second square's cross term properly.
**common_trap:** add-instead-of-subtract — computing (8 + 2√15) + (8 − 2√15) = 16 when the problem asks for their difference. Always re-read the operation sign between the two squares.
**takeaway:** The identity (A + B)² − (A − B)² = 4AB eliminates constant terms and doubles the cross term. Memorizing it saves full expansion. Here: 4 · √5 · √3 = 4√15.

## Q40
**difficulty:** Hard
**type:** Problem Solving
**topic:** Advanced Exponent Manipulation

If 4^x + 4^(−x) = 5/2, what is the value of 4^(2x) + 4^(−2x)?

- A) 17/4
- B) 21/4
- C) 25/4
- D) 4
- E) 5/2

**answer:** A
**fastest_path:** Square the given equation: (4^x + 4^(−x))² = 4^(2x) + 2 + 4^(−2x). So 25/4 = 4^(2x) + 2 + 4^(−2x). Subtract 2: 25/4 − 8/4 = 17/4.
**explanation:** Let S = 4^x + 4^(−x) = 5/2. Square both sides: S² = (4^x)² + 2(4^x)(4^(−x)) + (4^(−x))² = 4^(2x) + 2 · 4^(x+(−x)) + 4^(−2x) = 4^(2x) + 2 · 4⁰ + 4^(−2x) = 4^(2x) + 2 + 4^(−2x). Therefore (5/2)² = 25/4 = 4^(2x) + 2 + 4^(−2x). Solving: 4^(2x) + 4^(−2x) = 25/4 − 2 = 25/4 − 8/4 = 17/4.
**mistake_b:** Subtracted 1 instead of 2 from 25/4: 25/4 − 4/4 = 21/4. The middle term of (A + B)² is 2AB = 2 × 1 = 2, not 1.
**mistake_c:** Set 4^(2x) + 4^(−2x) = S² = 25/4 without subtracting the middle term. Forgot that (A + B)² = A² + 2AB + B², so A² + B² = S² − 2AB.
**mistake_d:** Approximated 4^x ≈ 2 and 4^(−x) ≈ 0.5 (if x ≈ 1/2), then computed 4^(2x) + 4^(−2x) ≈ 4 + 0.25 ≈ 4.
**mistake_e:** Confused 4^(2x) + 4^(−2x) with the original expression 4^x + 4^(−x) = 5/2 and repeated the given value.
**common_trap:** missing-middle-term — squaring (4^x + 4^(−x)) and writing 4^(2x) + 4^(−2x) = (5/2)² = 25/4 directly, omitting the 2AB = 2 term in the square expansion.
**takeaway:** Pattern: if a^x + a^(−x) = S, then a^(2x) + a^(−2x) = S² − 2. This follows from (A + B)² = A² + 2AB + B² with AB = a^x · a^(−x) = 1. Subtract 2 (not 1, not 0) from S².

## Q41
**difficulty:** Expert
**type:** Problem Solving
**topic:** Variable Exponents and Common Bases

If 2^x = 3^y = 6^z, where x, y, and z are positive real numbers, which of the following expresses z in terms of x and y?

- A) x/y
- B) xy
- C) xy/(x + y)
- D) (x + y)/xy
- E) x + y

**answer:** C
**fastest_path:** Let k = 2^x = 3^y = 6^z. Then 2 = k^(1/x), 3 = k^(1/y), 6 = k^(1/z). Since 6 = 2 × 3: 1/z = 1/x + 1/y → z = xy/(x + y).
**explanation:** Set all three expressions equal to a common value k. Express each prime base in terms of k: 2 = k^(1/x), 3 = k^(1/y), 6 = k^(1/z). The factorization 6 = 2 × 3 translates into: k^(1/z) = k^(1/x) · k^(1/y) = k^(1/x + 1/y). Equating exponents of k: 1/z = 1/x + 1/y. Solving: 1/z = (x + y)/xy → z = xy/(x + y). Numerical check: set z = 1, so 6^1 = 6. Then 2^x = 6 → x = log₂6 ≈ 2.585, and 3^y = 6 → y = log₃6 ≈ 1.631. Verify: xy/(x + y) ≈ (2.585 × 1.631)/(2.585 + 1.631) ≈ 4.216/4.216 = 1 = z. ✓
**mistake_a:** Took x/y with no structural justification — confusing exponent relationships with a simple ratio.
**mistake_b:** Multiplied x and y (result: xy), perhaps associating the product of bases 2 × 3 with the product of exponents.
**mistake_d:** Computed 1/z = 1/x + 1/y correctly but then wrote z = (x + y)/xy, which is 1/z (the reciprocal of the answer). This inversion is the most natural error in this problem.
**mistake_e:** Added x + y linearly, perhaps from the factorization 6 = 2 × 3 and misreading it as an exponent addition x + y.
**common_trap:** inversion-error — correctly reaching 1/z = 1/x + 1/y but then writing z = (x + y)/xy instead of inverting to z = xy/(x + y). The answer requires one more step: take the reciprocal.
**takeaway:** When A × B = C and A^(1/p) = B^(1/q) = C^(1/r) (all equal to a common base k), then 1/r = 1/p + 1/q → r = pq/(p + q). This harmonic-sum structure appears in work-rate and parallel-circuit problems as well as variable-exponent problems.
**related_reading:** reading-quant-04-algebra-and-equations
