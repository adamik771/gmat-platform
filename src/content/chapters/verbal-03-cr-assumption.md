## @cr-assumption

An **assumption** is an unstated premise the argument *requires* to work. Not a plausible add-on — a *necessary* link. If the assumption is false, the argument collapses.

**The negation test — the single most powerful technique for assumption questions.**

1. Take each answer choice.
2. **Negate** it (turn it into its logical opposite).
3. If the negated version *destroys* the argument, that's the assumption.
4. If the negated version leaves the argument intact, that's NOT the assumption.

**Example.** Argument: "Company X switched from annual to quarterly performance reviews. Turnover dropped from 22% to 14%. Therefore, the new review system caused the turnover drop."

Candidate answers:

- A) "The new review system was more expensive than the old one."
- B) "No other major change at Company X during the same period contributed to the turnover drop."

Negate A: "The new review system was NOT more expensive than the old one." Does the argument collapse? No — cost doesn't matter to the causal claim. A is NOT the assumption.

Negate B: "Another major change at Company X during the same period also contributed to the turnover drop." Does this destroy the argument? Yes — if there's another cause, the review system isn't necessarily *the* cause. B is the assumption.

The negation test is mechanical. It converts "does the author need this?" (vague, subjective) into "does the argument break if this is false?" (precise, testable).

**The question stem decoder:**

| Stem wording | Type |
|---|---|
| "…the argument depends on which of the following assumptions…" | Assumption |
| "…which of the following is assumed by the argument…" | Assumption |
| "…the conclusion follows logically from which of the following assumptions…" | Assumption |

**What assumptions typically look like.**

1. **"No other cause exists."** Rules out alternative explanations. Most common type.
2. **"The evidence is representative."** If the argument uses a specific example or study, it often assumes that example generalizes.
3. **"A necessary condition is met."** The argument assumes some prerequisite is true.
4. **"The mechanism works as described."** The argument assumes the causal chain actually functions.

**The "extreme language" filter on assumption questions.** Assumptions tend to be *modest* — "there's no other major cause," "the sample isn't systematically biased." Answer choices that are too strong ("every single alternative has been ruled out," "it is impossible for anything else to have contributed") usually go too far. The argument doesn't *need* that much — it only needs the modest version. When in doubt, pick the weakest phrasing that still makes the argument work.

**Assumption vs. strengthen — a subtle but frequent confusion.** A strengthener makes the argument *more likely* to be true. An assumption makes it *possible* for the argument to be true. Every assumption, if stated, would strengthen — but not every strengthener is an assumption. The assumption is the *minimum* the argument needs; strengtheners are additional support on top.

**Example.** Argument: a green-space/asthma causation claim.

- Strengthener: "Studies show vegetation absorbs particulate matter that triggers asthma."
- Assumption: "Higher-income families don't specifically prefer green-space neighborhoods for reasons that also lower their asthma rates." (A weaker, more defensive claim — but essential.)

The strengthener provides a positive mechanism; the assumption just rules out one of several confounds.

> **Recall check.** Without looking, describe the four steps of the negation test. Now apply it in your head to: Argument "X caused Y because X happened before Y." Which of these is the necessary assumption — (a) "X is a very common cause of Y in general," or (b) "Nothing else besides X plausibly caused Y"? (Answer: b. Negate a → argument survives if X is just a cause occasionally. Negate b → some other cause makes X unnecessary, argument breaks.) This is retrieval practice on a novel stimulus — the most effective form of learning consolidation.

**Trap to watch.** The negated answer choice often looks weird and overly strong when you first read it ("Something other than X definitely caused Y"). That's fine — the negation is meant to sound aggressive. The point is whether it breaks the argument, not whether it sounds natural.

**Worked example.** Apply the negation test to a clean case. Argument: "A hospital adopted a new hand-washing protocol; infection rates fell 40%; the protocol caused the drop." Candidate assumption: "No other infection-control change was introduced in the same period." Negate it: "Another infection-control change *was* introduced in the same period." The argument collapses — the drop could be due to that other change — so the statement is a required assumption. Run that mechanical four-step on every assumption question and you stop guessing.
